# Issue tracker: GitHub

Issues desta API vivem em `rodcordeiro/banky`. Use `gh issue` neste checkout. Toda issue planejada deve integrar o [Banky Project #11](https://github.com/users/rodcordeiro/projects/11), com `Status`, `Priority` e `Size` revisados.

PRs não são superfície de entrada para triagem. Trabalho transversal deve criar issues nos consumidores afetados e registrar dependências recíprocas.

Quando uma skill disser “publique no issue tracker”, crie uma GitHub issue neste repositório e confirme sua associação ao Project #11. Para buscar um ticket, use `gh issue view <numero> --comments`.
