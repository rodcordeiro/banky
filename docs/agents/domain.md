# Domain docs

Este é um repositório single-context. Antes de explorar, leia `CONTEXT.md` e os ADRs relevantes em `docs/adrs/`.

Se um arquivo não existir, prossiga sem criar placeholder. Use o vocabulário de `CONTEXT.md`; lacunas reais devem ser tratadas com domain modeling. Sinalize explicitamente qualquer proposta que contradiga um ADR.
